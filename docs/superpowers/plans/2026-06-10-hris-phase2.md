# HRIS Fase 2 Implementation Plan — Overtime & Reimbursement

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Modul lembur & reimbursement lengkap (pengajuan self-service, approval 2 langkah, lampiran bukti di DB, status PAID) sesuai spec `docs/superpowers/specs/2026-06-10-hris-phase2-design.md`.

**Architecture:** Pola project: server component + form POST → API route → redirect 303; logika di services; approval memakai engine yang ada dengan refactor dispatcher per module. File bukti disimpan BLOB (`file_contents`) terpisah dari metadata (`files`). Verifikasi per task `npx tsc --noEmit`; akhir: build + smoke test HTTP.

**Tech Stack:** Next.js 15, Prisma 6 + MySQL (collation utf8mb4_unicode_ci wajib untuk tabel baru), zod, Tailwind token-based.

```prisma
model OvertimeRequest {
  id                 String    @id @default(dbgenerated("(UUID())")) @db.Char(36)
  employeeId         String    @map("employee_id") @db.Char(36)
  selectedApproverId String?   @map("selected_approver_id") @db.Char(36)
  overtimeDate       DateTime  @map("overtime_date") @db.Date
  startTime          String    @map("start_time") @db.VarChar(5)
  endTime            String    @map("end_time") @db.VarChar(5)
  durationMinutes    Int       @map("duration_minutes")
  reason             String    @db.Text
  status             String    @default("DRAFT") @db.VarChar(50)
  approvalRequestId  String?   @map("approval_request_id") @db.Char(36)
  submittedAt        DateTime? @map("submitted_at") @db.DateTime(0)
  createdAt          DateTime  @default(now()) @map("created_at") @db.DateTime(0)
  updatedAt          DateTime? @updatedAt @map("updated_at") @db.DateTime(0)

  employee         Employee         @relation("OvertimeEmployee", fields: [employeeId], references: [id])
  selectedApprover Employee?        @relation("OvertimeApprover", fields: [selectedApproverId], references: [id])
  approvalRequest  ApprovalRequest? @relation(fields: [approvalRequestId], references: [id])

  @@index([employeeId, status], map: "idx_overtime_employee_status")
  @@map("overtime_requests")
}

model ReimbursementRequest {
  id                  String    @id @default(dbgenerated("(UUID())")) @db.Char(36)
  employeeId          String    @map("employee_id") @db.Char(36)
  reimbursementTypeId String    @map("reimbursement_type_id") @db.Char(36)
  selectedApproverId  String?   @map("selected_approver_id") @db.Char(36)
  expenseDate         DateTime  @map("expense_date") @db.Date
  amount              Decimal   @db.Decimal(15, 2)
  description         String    @db.Text
  attachmentFileId    String?   @map("attachment_file_id") @db.Char(36)
  status              String    @default("DRAFT") @db.VarChar(50)
  paidAt              DateTime? @map("paid_at") @db.DateTime(0)
  paidBy              String?   @map("paid_by") @db.Char(36)
  approvalRequestId   String?   @map("approval_request_id") @db.Char(36)
  submittedAt         DateTime? @map("submitted_at") @db.DateTime(0)
  createdAt           DateTime  @default(now()) @map("created_at") @db.DateTime(0)
  updatedAt           DateTime? @updatedAt @map("updated_at") @db.DateTime(0)

  employee          Employee          @relation("ReimbursementEmployee", fields: [employeeId], references: [id])
  selectedApprover  Employee?         @relation("ReimbursementApprover", fields: [selectedApproverId], references: [id])
  reimbursementType ReimbursementType @relation(fields: [reimbursementTypeId], references: [id])
  attachment        File?             @relation(fields: [attachmentFileId], references: [id])
  approvalRequest   ApprovalRequest?  @relation(fields: [approvalRequestId], references: [id])
  paidByUser        User?             @relation("ReimbursementPaidBy", fields: [paidBy], references: [id])

  @@index([employeeId, status], map: "idx_reimb_employee_status")
  @@map("reimbursement_requests")
}

model FileContent {
  fileId String @id @map("file_id") @db.Char(36)
  data   Bytes

  file File @relation(fields: [fileId], references: [id])

  @@map("file_contents")
}
```

Relasi balik: `Employee` += `overtimeRequests OvertimeRequest[] @relation("OvertimeEmployee")`, `overtimeApprovals OvertimeRequest[] @relation("OvertimeApprover")`, `reimbursementRequests ReimbursementRequest[] @relation("ReimbursementEmployee")`, `reimbursementApprovals ReimbursementRequest[] @relation("ReimbursementApprover")`; `ReimbursementType` += `requests ReimbursementRequest[]`; `ApprovalRequest` += `overtimeRequests OvertimeRequest[]`, `reimbursementRequests ReimbursementRequest[]`; `File` += `content FileContent?`, `reimbursementRequests ReimbursementRequest[]`; `User` += `reimbursementsPaid ReimbursementRequest[] @relation("ReimbursementPaidBy")`.

Jalankan `npx prisma migrate deploy` lalu `npx prisma generate`.
