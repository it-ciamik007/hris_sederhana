# Audit HRIS 2026-06-04

## Temuan Utama

- Banyak halaman masih scaffold dan belum mengikuti pola list-first.
- Approval kosong tidak punya empty state, filter, timeline, atau CTA.
- Attendance masih form-first, belum menjadi halaman operasional import/list.
- Evaluation builder terlalu terbuka dan membingungkan; belum ada edit untuk form lama.
- Test template/answer key terlalu rumit untuk alur kerja saat ini dan lebih baik disembunyikan sementara.
- Hak akses sudah ada di database, tetapi belum dipakai sebagai guard route/menu.
- Pengajuan cuti belum context-aware untuk karyawan biasa dan belum langsung membuat approval.
- UI terlalu polos dan belum konsisten seperti dashboard kit modern.

## Perbaikan Yang Sudah Dilakukan

- Menambahkan middleware permission guard untuk halaman dan API utama.
- Sidebar sekarang filter menu berdasarkan permission.
- Menambahkan halaman `settings/roles` untuk role-permission matrix.
- Menambahkan halaman `settings/defaults` untuk default company, shift, leave policy, dan leave types.
- Mengubah approval menjadi list-first dengan metric, search, filter, pagination, timeline, dan empty state.
- Mengubah attendance import menjadi list-first dengan batch table, metric, search, filter, pagination, dan upload action.
- Mengubah employees menjadi list-first dashboard table dengan metric, search, filter, pagination.
- Mengubah leave request agar admin bisa pilih karyawan, sedangkan user non-admin otomatis memakai employee profile dari session.
- Pengajuan cuti dari modal sekarang langsung submit ke approval engine.
- Draft leave request sekarang bisa disubmit dari list.
- Menambahkan approval token asli untuk link approve/reject WA.
- Menambahkan fallback HRD jika pengaju tidak punya direct SPV.
- Evaluation form lama sekarang bisa diedit lewat `/evaluations/forms/[id]/edit`.
- Builder create untuk evaluation disembunyikan di disclosure agar list tetap menjadi fokus.
- Modul test template lama disembunyikan dari UI dan route lama diarahkan ke `/tests/scan`.
- Halaman kosong seperti documents, announcements, overtime, reimbursement, recruitment, training, assets diganti menjadi list placeholder konsisten.
- UI shell dibuat lebih modern: sidebar polished, topbar sticky, cards, gradients halus, hover state, dan layout lebih hidup.
- Role-permission matrix diganti menjadi tab per role dengan pencarian permission.
- API action utama sekarang ikut dikunci permission melalui middleware, bukan hanya halaman.
- Default settings sekarang editable: company, default shift, leave policy, annual quota, dan behavior cuti.
- Leave Types sekarang bisa ditambah dan diedit dari Settings Defaults.
- WhatsApp Settings sekarang menyimpan Base URL, API key, Instance ID, nomor pairing, dan fallback approval phone ke `app_settings`.
- Menambahkan flow Create WAM Instance dari UI; hasil `api_key` dan `instance_id` disimpan otomatis.
- Menambahkan QR dan pairing-code tools untuk WAM.
- Notification worker dibuat daemon loop agar queue WhatsApp diproses otomatis saat worker berjalan.
- Leave approval sekarang menyambung ke WhatsApp queue: submit cuti membuat approval token dan antrean pesan ke approver.
- Link approve/reject WhatsApp sekarang menjalankan action token, mengubah status cuti, membuat notifikasi step berikutnya, dan mengirim hasil akhir ke karyawan.
- Evaluation section layout sekarang tersimpan di database lewat migrasi `0003_evaluation_section_layout`.
- Evaluation builder sekarang menyimpan dan memuat ulang description, columns, width, required, options, dan tipe jawaban.
- Evaluation renderer sekarang membedakan text, textarea, yes/no, multiple choice, checkbox, number, dan rating.
- Test builder tidak lagi menjadi alur utama.
- Default saldo cuti/annual quota diubah menjadi 16 hari lewat migrasi `0004_leave_balance_default_16`.
- Migrasi `0005_initialize_leave_balances` membuat saldo cuti tahun berjalan untuk karyawan existing dan leave type yang memotong saldo.
- Submit cuti sekarang mengecek sisa saldo jika leave type memotong saldo.
- Approval final `APPROVED` sekarang mengurangi `leave_balances.used` dan `leave_balances.remaining`.
- Halaman leave menampilkan sisa cuti tahun berjalan untuk user yang punya employee profile.
- Employees sekarang punya export Excel dan import Excel upsert berdasarkan `employee_number`.
- Import karyawan otomatis membuat branch, department, position jika belum ada, dan membuat saldo cuti awal.
- Tests sekarang menjadi `Scan OCR Deret Angka`: kamera/upload foto, OCR di browser, analisis pola angka naik/turun, dan penanda titik salah.
- Scanner sekarang bisa membaca workbook `Jawaban TES BS dan Angka.xlsx`, mengambil angka merah dari sheet `Asli`, lalu mengoreksi jawaban peserta dengan default `atas ke bawah`; mode auto hanya berpindah ke `bawah ke atas` jika atas-ke-bawah nol benar.
- Menambahkan toggle mode terang/gelap di topbar serta dark styling untuk shell dan header utama.
